# 📖 Agenda Pastoral Digital

Sistema desenvolvido para organizar pedidos pastorais de forma simples, prática e centralizada, facilitando o acompanhamento e a gestão das informações da comunidade.

## ✨ Funcionalidades

- Cadastro de pedidos pastorais
- Registro de nome e telefone
- Campo para descrição dos pedidos
- Organização das informações em um único local
- Interface simples e acessível

## 🎯 Objetivo do Projeto

O projeto foi criado para ajudar comunidades pastorais a organizarem pedidos de oração e informações importantes de maneira mais eficiente, reduzindo a desorganização causada pelo uso exclusivo do WhatsApp.

## 🛠 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB

## 📚 Projeto de Extensão

Este sistema foi desenvolvido como projeto de extensão acadêmica, com foco em inovação, organização comunitária e impacto social.
